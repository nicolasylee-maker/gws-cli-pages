Privacy Policy

Last updated: September 28, 2026

gws CLI is a personal command-line tool built and used by a single developer (the "Owner") to access their own Google account data. This policy explains how that data is handled.

What data is accessed

gws CLI connects to the Owner's own Google account using Google's OAuth authorization flow and may access:

  • Gmail messages (read and/or send, depending on the command used)
  • Google Drive files
  • Google Calendar events

How data is used

Data retrieved from these APIs is used only to perform the action the Owner requested at the command line (for example, reading an email, listing files, or creating a calendar event). Data is processed locally on the Owner's own machine.

Data storage and sharing

gws CLI does not upload, sell, share, or transmit any Google account data to third parties or external servers. Any data retrieved is used transiently for the requested command or cached locally on the Owner's own device. No data is shared with any other person, company, or service.

Single-user tool

This application is not distributed publicly and is not intended for use by anyone other than its Owner. It is not offered as a service to the public.

Revoking access

Access can be revoked at any time via Google Account → Security → Third-party access.

Contact

Questions about this policy can be sent to nicolasylee@gmail.com.
